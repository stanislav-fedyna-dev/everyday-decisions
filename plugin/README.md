# everyday-decisions

An agent skill that makes one firm, defensible decision for everyday choices: purchases, home, travel, habits, how to spend time or money.

Ask "X or Y?" and get one decision, the trade-off you're accepting, and a condition for revisiting it.

- Skill: `skills/everyday-decisions/SKILL.md`
- Docs, install options and examples: https://github.com/stanislav-fedyna-dev/everyday-decisions

## Disclaimer

This skill gives general information to help you make everyday choices. **It is not professional medical, legal or financial advice.** For health questions, see a doctor; before signing contracts, get legal advice; for investments, talk to a licensed financial adviser. In emergencies, contact local emergency services.
