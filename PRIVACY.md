# Privacy policy

_Last updated: 2026-11-24_

**everyday-decisions** is a set of plain-text instructions (a skill) that your AI agent reads. It contains no code, no tracking, and no servers.

- **The author collects nothing.** The skill does not send, store or log any data anywhere.
- **Your agent does the work.** When the skill runs, your agent (for example Claude) may use the tools you have enabled, such as web search for current prices or rules, and may use context it already has about you. That happens under the privacy terms of the agent and tools you use, not this project.
- **Saving notes is opt-in.** The skill may *offer* to save a decision log to your own notes app. It never creates anything without your explicit yes.

Questions: open an issue at https://github.com/stanislav-fedyna-dev/everyday-decisions/issues
